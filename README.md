# lawn-project

The mod is based on [ResoddedFramework](https://github.com/lawnproject/resoddedframework)

## Packages


- Mod
  - `lawn-app`: Mod code (based on LawnProject/ResoddedFramework)
  - `lawn-assets`: Mod files
- Library
  - `lawn-imagelib`: ImageLib (extracted from ResoddedFramework)
  - `lawn-paklib`: PakLib (extracted from ResoddedFramework)
  - `lawn-libs`: Third-party libraries (extracted from ResoddedFramework)
- Tools:
  - `pvz-pakc`: CLI for packing/unpacking `.pak` file
  - `pvz-reanimc`: CLI for compiling/dumping `.reanim`/`.reanimc` file
