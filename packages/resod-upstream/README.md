# resod-upstream
This package hosts a copy of the upstream ResoddedFramework
for us to build upstream, take source drops or contribute.

## Setup
To setup for taking source drop run `task setup` or clone Piston's fork manually.

To setup for contributing clone your own fork

## Building
To verify everything build run `task build -- all` which builds x64/x86 and debug/release
